# Agriculture Crop Production Prediction

## Overview

This project predicts agricultural crop yield using machine learning techniques based on cultivation cost, production cost, crop type, and state.

## Workflow

- Data Cleaning
- Exploratory Data Analysis
- Statistical Analysis
- Feature Engineering
- Linear Regression
- Random Forest Regression
- Model Evaluation
- Feature Importance

## Results

Random Forest outperformed Linear Regression with improved prediction accuracy.

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
