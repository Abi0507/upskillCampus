# Smart City Traffic Forecasting

## Overview

This project forecasts vehicle traffic using machine learning models trained on historical traffic data.

## Workflow

- Data Cleaning
- Exploratory Data Analysis
- Statistical Analysis
- Feature Engineering
- Linear Regression
- Random Forest Regression
- Model Evaluation
- Feature Importance

## Results

Random Forest achieved better performance than Linear Regression in predicting traffic volume.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
